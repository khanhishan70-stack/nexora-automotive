# Nexora Automotive

Futuristic automotive showcase built with React and Vite.

## Local development

```bash
npm ci
npm run dev
```

## Verify

```bash
npm test
npm run build
```

## GitHub Pages

The published project site is:

https://khanhishan70-stack.github.io/nexora-automotive/

For a custom domain, set `VITE_BASE_PATH=/` before building, add a `CNAME` file containing your domain to the published `dist/` root, then configure the domain's DNS records to point to GitHub Pages. A domain name is required before that final DNS step can be completed.
